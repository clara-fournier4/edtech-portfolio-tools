## What is EdTech Portfolio?

EdTech Portfolio gathers practical education utilities in one browser experience for instructors and students working on reading, number skills, and school–family messaging. Inside the collection you will find phonics progress logging, worksheet builders for print, decodable text generation, math assessment records, multiplication-table practice, and newsletter layouts families can reuse.

Generation and review center on explicit curriculum rules: materials can be produced under those constraints and inspected on their own terms afterward. Educators who want consistent packs, orderly assessment steps, and resources tied to particular phonics or curriculum targets can work entirely online—no desktop package to install.

- Log phonics assessment outcomes and follow learner progress over time.

## Typical use

A common path looks like this:

1. Launch EdTech Portfolio in a supported browser.
2. Pick a literacy, math, worksheet, passage, practice, or newsletter tool.
3. Supply learner, curriculum, or classroom details as needed.
4. Turn on the rules or options that fit the task.
5. Inspect the output or the assessment entry you created.
6. Print worksheets or passages when paper is required.
7. Validate generated content yourself before learners use it.

## FAQ

### Is a desktop install required?

No. The portfolio is built for in-browser use and does not ask you to install a native application.

### Which resource types are supported?

You can generate printable worksheets, decodable passages, times-tables practice, and family newsletter templates.

### Does assessment tracking exist?

Yes—for phonics assessments and for mathematics assessments.

### How do curriculum rules fit in?

Rules can sit inside the content workflow so outputs follow defined requirements and remain open to independent review.

### How are updates obtained?

Open the hosted build again, or refresh a clone with:

`git pull`

### Local files will not load properly—what next?

Serve the site through a local web server instead of raw `file://` paths. Confirm the clone is complete and that the browser is up to date.

### How do I ask for help?

File a repository issue describing the tool involved, the steps you took, and browser or local-serve context that matters.
